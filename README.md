### Projects

- **[Arch-Linux-Hardening](https://github.com/Qantrex/Arch-Linux-Hardening)**: Bash scripts that harden a Linux system (SSH, users, file permissions, services) and check the result.
- **[ITSI-7.5](https://github.com/Qantrex/ITSI-7.5)**: web app behind Caddy (HTTPS) and a ModSecurity WAF, with PHP and MariaDB in Docker Compose.
- **[dots](https://github.com/Qantrex/dots)**: my Arch Linux + Hyprland setup.
- **Homelab**: two Raspberry Pis running Docker, Pi-hole with Unbound, Tailscale and a Cloudflare Tunnel with Zero Trust access.
